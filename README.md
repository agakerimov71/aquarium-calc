# Калькулятор аквариумиста

Небольшой проект на Python для тех, кто заводит аквариум. По размерам
аквариума он считает объем воды, сколько рыб можно поселить и сколько
литров менять при еженедельной подмене.

## Состав проекта

| Файл | Что делает |
|---|---|
| `volume.py` | `tank_volume(length, width, height)`: объем в литрах по размерам в см |
| `stocking.py` | `max_fish(volume_l, fish_length_cm)`: число рыб по правилу 1 см рыбы на 1,5 л |
| `water_change.py` | `weekly_change(volume_l, percent=25)`: литры для подмены |
| `main.py` | собирает все расчеты и печатает результат |

## Как запустить

Нужен Python 3.8 или новее, сторонние библиотеки не нужны.

    git clone https://github.com/agakerimov71/aquarium-calc.git
    cd aquarium-calc
    python3 main.py 60 30 40 4

Аргументы: длина, ширина, высота аквариума в сантиметрах и длина взрослой
рыбы в сантиметрах. Без аргументов программа покажет подсказку.

## Пример вывода

    Объем аквариума: 72.0 л
    Можно поселить рыб длиной 4 см: 10
    Подмена воды раз в неделю: 18.0 л

## Ограничения

Расчет числа рыб примерный и подходит для небольших мирных рыб.
Функция `weekly_change` принимает процент подмены от 1 до 50.
